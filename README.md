# ✊✋✌️ Rock Paper Scissors Game

## 📌 Project Overview

Rock Paper Scissors is an interactive web-based game developed using HTML, CSS, and JavaScript. The game allows users to play against the computer, which generates random choices and determines the winner based on the standard game rules.

## 🚀 Features

* Interactive user interface
* Player vs Computer gameplay
* Random computer choice generation
* Real-time score tracking
* Win, lose, and draw detection
* Dynamic result messages
* Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 🎮 How to Play

1. Choose Rock, Paper, or Scissors.
2. The computer randomly selects its move.
3. The game compares both choices.
4. Scores are updated automatically.
5. Continue playing to improve your score.

## 📊 Game Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Same choices result in a Draw
